POST requests

POST sends data in the request body instead of the URL. A CGI script gets that body on its standard input. An upload sends a file as a multipart/form-data body, and the server saves it in upload/.

POST Form data to a CGI script

Body sent as application/x-www-form-urlencoded, e.g. name=Marvin&message=hi.

POST File upload

Sent to /upload as multipart/form-data. Uploaded files can then be removed from the DELETE page.

See uploaded files
