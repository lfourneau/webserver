webserv

An HTTP server written from scratch in C++. This site is served by it, and each page below tests one of its features: static files, GET, POST, DELETE, CGI scripts in Python and PHP, and HTTP status codes.

FILE

Static files

HTML, CSS, JS, images, PDF and text, each sent with the right Content-Type.
GET

GET requests

Fetch files and send query strings to a CGI script.
POST

POST & upload

Send form data to a script and upload files to the server.
DEL

DELETE

List the uploaded files and delete them from the server.
CGI

CGI

Pages generated by Python and PHP scripts: env, clock, calculator.
4xx

Status codes

Trigger 200, 404, 405, 413, 500, 504 and more, and see what comes back.

How a request travels

The browser opens a socket to the server and sends a request line, headers and an optional body. The server parses them, then either reads a file from html_files/, runs a script in cgi-bin/, or writes or removes a file in upload/. It then sends back a status line, headers and the content.

GET /index.html HTTP/1.1
Host: localhost:8080
