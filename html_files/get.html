GET requests

GET asks the server for a resource. For a static file it sends the file. For a CGI script it runs the script and passes it whatever follows the ? in the URL (the query string).

GET Query string to a CGI script

The browser builds /cgi-bin/hello.py?name=...&color=... and the script reads it from QUERY_STRING.
