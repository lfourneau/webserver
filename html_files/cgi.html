CGI scripts

For a .py or .php file, the server does not send the file itself. It forks, runs the interpreter on the script, gives it the request through environment variables and standard input, and sends back what the script prints.

Scripts that fail on purpose

A good server answers 500 when the script crashes and 504 when it runs for too long, instead of hanging.

If the server has no CGI timeout yet, slow.py blocks it for 10 seconds.
